# ⏱️ Cronômetro em Python (Tkinter)

Uma aplicação desktop simples e intuitiva de cronômetro desenvolvida em Python utilizando a biblioteca gráfica **Tkinter**.

---

## 📌 Funcionalidades

- **Iniciar / Continuar:** Inicia a contagem do tempo a partir de `00:00:00` ou retoma do ponto onde parou.
- **Pausar:** Pausa a contagem sem perder o progresso atual.
- **Zerar:** Interrompe a contagem e reseta o marcador para o tempo inicial.
- **Interface Intuitiva:** Layout limpo e moderno adaptado para desktop.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Tkinter** *(biblioteca nativa para interfaces gráficas)*
